# Security

Please report a security problem privately, not in a public issue.

- **In card-kit** (the card format and its tools, the edgible-cards skill, edgible-mcp, mcp-signin): use **Report a vulnerability** on this repository's Security tab, or [contact Edgible](https://www.edgible.ai/contact/).
- **In a card** (edgible-org/cards): report it on that repository's Security tab.
- **In an app a card runs** (WordPress, Memos and the rest): report it to that app's own project. Tell us too, so we can update or pause the card.
- **In Edgible's hosted service** (sign-in, the gateway, the console, the agent): [contact Edgible](https://www.edgible.ai/contact/).

Say what you found, how to reproduce it, and what it affects. We will reply, keep you posted while we fix it, and credit you if you wish once a fix is out.

Everything here is open source and comes as is, with no warranty: [what that means](https://cards.edgible.org/no-warranty/).
