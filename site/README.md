# Catalog site assets

`card-site` copies this folder into every build as `assets/`, so the catalog looks like Edgible's guides (guides.edgible.com), from the same files.

- `fonts/`: Jost, standing in for Edgible's licensed brand face, and Iosevka for code. Both are under the SIL Open Font License; the licence texts are beside them.
- `images/`: the Edgible logo, symbol and favicon. The logo's wordmark is set in Outfit (SIL Open Font License, weight 480, its two-storey g), as outlines in `edgible-logo-white.svg`; the `.png` is the same artwork. They are Edgible's trademarks, not covered by this repo's MIT License: use them only for Edgible's own sites.
